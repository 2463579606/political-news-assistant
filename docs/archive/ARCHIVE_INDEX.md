## 💡 为什么归档这些文档？

### 1. 避免混淆
- 多个版本的同类文档容易造成混淆
- 只保留最新版本，确保信息一致性

### 2. 简化维护
- 减少需要维护的文档数量
- 避免重复更新多个文档

### 3. 提高效率
- 快速找到最新文档
- 避免阅读过时信息

### 4. 保持历史
- 归档而非删除，保留历史记录
- 需要时可以查阅
