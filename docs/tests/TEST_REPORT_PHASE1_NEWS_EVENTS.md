## 🔟 已知限制和改进方向

### 当前限制

1. **Claude API依赖**
   - 影响: 无API Key时使用模拟提取
   - 优先级: 中
   - 解决: 用户需要配置ANTHROPIC_API_KEY

2. **情感分析准确性**
   - 影响: 基于词典，准确率有限
   - 优先级: 高
   - 解决: Phase 3集成FinBERT

3. **板块映射覆盖**
   - 影响: 部分细分板块未覆盖
   - 优先级: 低
   - 解决: 持续添加关键词

### Phase 3改进计划

#### FinBERT集成
```
当前: 基于词典（准确率~60%）
目标: FinBERT模型（准确率~76%）
提升: +16个百分点
```

```
当前: 关键词匹配
目标: ChromaDB语义搜索
```
