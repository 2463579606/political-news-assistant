## 快速开始

### 方法1: 直接打开HTML文件 (推荐)

1. **启动后端服务**
   ```bash
   cd /path/to/political-news-assistant/src/backend

   # 启动v2 API服务器
   node server-v2.js
   ```

2. **打开前端界面**
   - 在浏览器中打开: `src/frontend/index.html`
   - 或双击 `index.html` 文件

### 方法2: 使用本地服务器

```bash
# 进入前端目录
cd /path/to/political-news-assistant/src/frontend

# 使用Python启动简单HTTP服务器
python3 -m http.server 8080

# 或使用Node.js
npx http-server -p 8080

# 浏览器访问
http://localhost:8080/index.html
```

## 使用说明

### 决策生成

#### 1. 生成单个决策

**步骤**:
1. 在"股票代码"输入框输入股票代码 (如: `000001.SZ`)
2. 点击"生成决策"按钮
3. 等待2-5秒查看结果

**股票代码格式**:
- 深交所: `000001.SZ`, `000002.SZ`, `300001.SZ`
- 上交所: `600519.SH`, `688001.SH`

**结果展示**:
```
┌─────────────────────────────────────┐
│ 强烈买入          置信度: 85%        │
├─────────────────────────────────────┤
│ 综合评分: 78.50                      │
│ 技术面: 75.20  资金流向: 68.30       │
│ 新闻舆情: 82.10  板块轮动: 75.50     │
├─────────────────────────────────────┤
│ 💡 决策建议:                        │
│ 基于多维度分析，建议适度买入该股票   │
│ 风险等级: 低                        │
└─────────────────────────────────────┘
```

#### 2. 批量决策

**步骤**:
1. 点击"批量决策 (3只股票)"按钮
2. 系统自动分析: `000001.SZ`, `600519.SH`, `000002.SZ`
3. 显示成功率统计

**用途**:
- 快速对比多只股票
- 筛选投资标的
- 组合优化分析

### 决策历史

#### 查询历史决策

**步骤**:
1. 在"决策历史"卡片输入股票代码
2. 点击"查询历史"按钮
3. 查看历史决策列表

**历史记录信息**:
- 决策时间
- 决策类型 (买入/卖出/持有)
- 综合评分
- 置信度

**点击历史记录**:
- 可在主决策区域显示完整信息
- 方便对比不同时期的决策变化

### 实时推送

#### WebSocket连接状态

- 🟢 **实时连接**: WebSocket已连接
- 🔴 **未连接**: WebSocket断开

系统会自动尝试重连。

#### 实时推送消息

**消息类型**:
1. **决策推送**: 生成新决策时实时推送
2. **告警推送**: 监控异常时推送告警
3. **系统消息**: WebSocket连接状态更新

**推送内容**:
```
[17:45:23] 📊 决策推送: 000001.SZ - 适度买入
[17:45:30] 🚨 告警: [WARNING] 000001.SZ评分异常下降
[17:46:00] 💓 心跳检测
```

### 回测功能

#### 1. 配置回测参数

**必需参数**:
- **股票代码**: 要回测的股票
- **开始日期**: 回测起始日期
- **结束日期**: 回测结束日期

**策略参数**:
- **买入阈值** (0-100): 评分高于此值买入
- **卖出阈值** (0-100): 评分低于此值卖出
- **止损率** (%): 亏损达到此比例止损
- **止盈率** (%): 盈利达到此比例止盈

**推荐配置**:
```
保守策略:
- 买入阈值: 80
- 卖出阈值: 20
- 止损率: 5%
- 止盈率: 10%

激进策略:
- 买入阈值: 60
- 卖出阈值: 40
- 止损率: 10%
- 止盈率: 20%
```

#### 2. 查看回测结果

**核心指标**:
- **总收益率**: 整体收益百分比
- **交易次数**: 总买卖次数
- **胜率**: 盈利交易占比
- **最大回撤**: 最大连续亏损
- **夏普比率**: 风险调整后收益
- **年化收益率**: 年度化收益率

#### 3. 收益曲线

**图表说明**:
- X轴: 交易日期
- Y轴: 累计收益率 (%)
- 蓝色区域: 收益走势
- 鼠标悬停: 查看具体数值

#### 4. 交易明细

**列信息**:
- **序号**: 交易顺序
- **类型**: 买入 (绿色) / 卖出 (红色)
- **日期**: 交易日期
- **价格**: 成交价格
- **收益率**: 本次交易收益率

## 常见问题

### Q1: 打开页面显示空白?

**A**: 检查以下几点:
1. 确保后端服务已启动:
   ```bash
   node server-v2.js
   ```
2. 检查浏览器控制台是否有错误
3. 尝试刷新页面 (Ctrl+F5 / Cmd+Shift+R)

### Q2: 点击"生成决策"没反应?

**A**: 可能原因:
1. 后端服务未启动 - 启动 `server-v2.js`
2. 端口错误 - 确保使用3002端口
3. 网络错误 - 检查浏览器控制台错误信息

### Q3: WebSocket显示"未连接"?

**A**:
1. 确保v2服务器运行正常
2. 检查防火墙设置
3. 刷新页面重新连接

### Q4: 回测失败显示错误?

**A**:
1. 检查股票代码格式是否正确
2. 确保日期范围内有历史数据
3. 查看错误信息了解具体原因

### Q5: 如何修改后端API地址?

**A**: 编辑HTML文件中的API地址:
```javascript
// 查找并替换
axios.post('http://localhost:3002/api/v2/decision/generate', ...)

// 修改为你的地址
axios.post('http://your-domain:3002/api/v2/decision/generate', ...)
```

## 性能优化建议

### 1. 数据缓存

系统已实现智能缓存:
- 首次查询: 从数据库获取
- 5分钟内重复查询: 从缓存返回
- 性能提升: 24.1%

### 2. 批量操作

建议使用批量决策功能:
- 一次性分析多只股票
- 减少网络请求
- 提升效率

### 3. WebSocket实时推送

启用WebSocket推送:
- 实时获取决策更新
- 减少轮询请求
- 降低服务器负载
