## 1️⃣ 需求理解确认

### 1.1 产品愿景

**从**: "时政新闻助手"（新闻聚合工具）
**到**: "AI智能投资决策助手"（投资决策系统）

**核心价值主张**:
> "透过时政财经新闻的表象，AI帮您发现投资机会，提前布局，精准决策"

### 1.2 三大核心价值

#### 价值1: 信息降噪 🎯
- **现状**: 用户需要1-2小时阅读筛选新闻
- **目标**: 5分钟读完重要新闻
- **实现**: AI自动过滤无关信息，只保留重要内容

#### 价值2: 洞察发现 🔍
- **现状**: 常人只能看到新闻表面
- **目标**: 识别常人忽视的蛛丝马迹
- **实现**: AI学习时政新闻，发现隐含的投资线索

#### 价值3: 决策支持 💡
- **现状**: 用户只能看到板块方向，不知道具体买哪只股票
- **目标**: 具体到股票代码的操作建议
- **实现**: AI给出买入/卖出/持有建议，量化风险评估

### 1.3 功能需求清单

#### 核心功能模块

**模块1: 智能新闻分析**
```
输入: 时政财经新闻
处理:
  - 事件自动提取（政策/会议/宏观数据/突发事件）
  - 情感分析（正面/中性/负面）
  - 板块映射（关联受影响的行业和股票）
  - 相似事件检索（基于历史案例对比）
输出: 结构化的事件数据
```

**模块2: 多维度市场分析**
```
输入: 股票代码 + 新闻事件
处理:
  - 技术分析（MACD/RSI/KDJ/BOLL等技术指标）
  - 资金流向（主力资金、北向资金追踪）
  - 板块轮动（识别热点板块切换）
  - 综合评分（多维度量化评分）
输出: 各维度评分和总分
```

**模块3: 投资决策建议**
```
输入: 股票代码 + 评分数据
处理:
  - 生成明确建议（买入/卖出/持有）
  - 计算目标价位（第一目标、第二目标）
  - 量化风险评估（风险等级）
  - 给出止损止盈点位
输出: 具体的投资决策
```

**模块4: 持续学习优化**
```
输入: 历史建议 + 实际结果
处理:
  - 记录所有投资建议
  - 追踪实际结果
  - 评估准确率
  - 自动优化参数
输出: 不断提升的预测准确率
```

### 1.4 非功能需求

**性能要求**:
- 新闻分析响应时间: < 10秒
- 综合评分计算时间: < 5秒
- 相似事件检索时间: < 500ms
- 系统可用性: > 99%

**数据要求**:
- 历史数据覆盖: 近5年
- 数据更新频率: 实时（新闻）/ 日度（行情）
- 数据准确性: > 99%

**质量要求**:
- 决策准确率目标: > 70%
- 事件提取准确率: > 80%
- 情感分析准确率: > 75%

##### 2.1.1 Claude API - 事件提取 ✅ 高度可行
- **能力**: 强大的自然语言理解
- **准确率**: 预计 > 85%
- **成本**: $0.003/1K tokens（可接受）
- **风险**: 低 - API稳定可靠
- **结论**: ✅ **可采用**

##### 2.1.2 FinBERT - 情感分析 ✅ 可行
- **准确率**: 76% (Financial PhraseBank)
- **部署**: 可本地部署或通过HuggingFace API
- **成本**: 低（本地部署）或免费（HF推理API）
- **风险**: 中 - 需要针对中文金融新闻微调
- **建议**: 先用预训练模型，准确率不够再微调
- **结论**: ✅ **可采用，预留微调时间**

##### 2.1.3 FinGPT - 金融分析 ⚠️ 需验证
- **能力**: 金融分析和报告生成
- **成熟度**: 开源项目，快速迭代
- **部署**:
  - 方案A: 使用API（如果有）
  - 方案B: 本地部署13B模型（需要GPU）
  - 方案C: 用Claude API替代
- **风险**: 高 - 部署复杂，需要GPU资源
- **建议**:
  - Phase 1-2: 使用Claude API替代
  - Phase 3: 评估是否部署FinGPT
- **结论**: ⚠️ **分阶段采用**

##### 2.1.4 RAG + ChromaDB - 相似事件检索 ✅ 可行
- **技术**: RAG（检索增强生成）成熟
- **向量库**: ChromaDB轻量易用
- **效果**: 相似事件检索准确率预计 > 70%
- **风险**: 低 - 技术成熟
- **结论**: ✅ **可采用**

## 4️⃣ 风险识别

### 4.1 技术风险

#### 风险1: AI模型准确率不达标 🔴 高
**描述**: FinBERT中文金融情感分析准确率可能< 75%
**影响**: 决策质量下降
**概率**: 40%
**缓解**:
- Phase 1测试准确率，及时发现问题
- 预留Phase 3进行微调
- 备选方案：使用Claude API替代
- 降低权重：情感分析只占综合评分的一部分

#### 风险2: 数据源不稳定 🟡 中
**描述**: 新闻爬虫可能被封IP
**影响**: 新闻数据获取失败
**概率**: 30%
**缓解**:
- 多数据源备份
- 添加请求间隔和User-Agent轮换
- 考虑使用付费新闻API服务
- 实现监控和告警

#### 风险3: FinGPT部署困难 🟡 中
**描述**: 本地部署FinGPT需要GPU资源，可能无法部署
**影响**: 无法使用FinGPT进行金融分析
**概率**: 50%
**缓解**:
- Phase 1-2使用Claude API替代
- Phase 3评估是否有必要部署
- 如果不部署，继续使用Claude API
- 使用云GPU服务（如AutoDL）

#### 风险4: Tushare免费额度不够 🟢 低
**描述**: 500次/天可能不够
**影响**: 需要升级付费版（¥3000/年）
**概率**: 20%
**缓解**:
- Phase 1评估实际使用量
- 优化API调用（缓存、批量查询）
- 备选数据源：AKShare

#### 风险5: 相似事件检索效果不佳 🟡 中
**描述**: 历史事件数量不够，检索效果差
**影响**: 经验参考价值低
**概率**: 30%
**缓解**:
- 尽可能多地回填历史数据
- 使用多个向量数据库备选
- 如果效果不佳，降低权重

### 4.2 项目风险

#### 风险6: 时间延期 🟡 中
**描述**: 某些模块开发时间超过预期
