## 1. 产品概述

### 1.1 产品定位
一个专注于时政、财经、政治新闻的智能聚合与AI助手平台，帮助用户高效获取全球关键信息并进行深度分析，辅助决策。

### 1.2 目标用户
- 关注时政新闻的投资者
- 需要政治经济信息辅助决策的专业人士
- 希望高效获取新闻但不想被娱乐信息干扰的用户

### 1.3 核心价值
- **信息聚合**：一站式获取国内外时政要闻
- **智能过滤**：自动屏蔽娱乐类无关信息
- **AI辅助**：智能总结、归纳、深度追问
- **专注高效**：节省时间，提升信息获取质量

## 5. 用户故事

### US1: 查看每日新闻
**作为**投资者
**我想要**每天早上快速了解前一天的时政要闻
**以便**辅助我的投资决策

**验收标准**:
- 每日早报在早上8点前准备好
- 包含最重要的10-20条新闻
- 每条新闻有AI生成的1-2句话总结

### US2: 深度了解事件
**作为**关注时政的用户
**我想要**对感兴趣的新闻进行追问
**以便**获取更多背景信息和深度分析

**验收标准**:
- 点击"追问"按钮即可进入对话
- AI能够理解上下文
- AI能主动检索相关信息
- 支持多轮对话

### US3: 过滤无关信息
**作为**专注的用户
**我想要**不看到娱乐类新闻
**以便**保持专注，不被干扰

**验收标准**:
- 默认过滤娱乐类新闻
- 可以自定义过滤规则
- 过滤效果准确率 > 95%

### US4: 追踪重大事件
**作为**用户
**我想要**重大事件发生时立即收到通知
**以便**及时了解重要动态

**验收标准**:
- 重大事件发生时系统通知
- 通知不过于频繁（每日 < 5次）
- 可以关闭通知

## 6. 技术选型（初步）

### 6.1 前端技术栈
- **Web框架**: Next.js 15 (React 19)
- **桌面端**: Electron / Tauri
- **UI组件**: shadcn/ui
- **状态管理**: Zustand
- **样式**: Tailwind CSS

### 6.2 后端技术栈
- **运行时**: Node.js (Bun)
- **框架**: Hono / Next.js API Routes
- **数据库**: PostgreSQL (主) + Redis (缓存)
- **ORM**: Drizzle ORM

### 6.3 AI能力
- **LLM**: Claude API (用户自备Key)
- **向量检索**:（可选）用于新闻相关性和推荐

### 6.4 数据源
- **新闻API**: NewsAPI、GNews、或聚合服务商
- **备用**: RSS订阅源

### 6.5 部署
- **云端**: Vercel / Fly.io
- **本地**: Docker compose
- **桌面**: 打包分发

## 9. 成功指标

## 10. 风险与依赖

### 10.1 技术风险
- **新闻API限制**: 需要备用方案（RSS）
- **AI成本**: 用户自备Key需明确告知成本
- **爬取合规性**: 使用正规API服务

### 10.2 产品风险
- **信息准确性**: 多源交叉验证
- **时效性**: 优化缓存策略
- **用户习惯**: 需要培养使用习惯
