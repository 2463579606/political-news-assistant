## 🖥️ 操作系统镜像选择

### 推荐：Ubuntu 22.04 64位

**为什么选Ubuntu？**
- ✅ 免费开源
- ✅ 社区支持好
- ✅ 命令与CentOS类似
- ✅ 软件包丰富（apt-get）
- ✅ 长期支持（LTS）

**其他选项对比：**

| 镜像 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| Ubuntu 22.04 | 新、稳定、包多 | - | ⭐⭐⭐⭐⭐ |
| Ubuntu 20.04 | 成熟稳定 | 版本稍旧 | ⭐⭐⭐⭐ |
| CentOS 7.9 | 企业级 | 2024年停止维护 | ⭐⭐⭐ |
| Alibaba Cloud Linux | 阿里云优化 | 社区小 | ⭐⭐⭐⭐ |

**❌ 不推荐**：Windows Server
- 需要额外授权费（贵）
- 配置Linux环境更复杂
- 不适合Node.js应用

## 🛒 购买步骤详解

### 第一步：登录阿里云

1. 打开浏览器，访问：https://www.aliyun.com
2. 注册/登录账号
3. 完成**实名认证**（必需！）
   - 需要身份证
   - 通常几分钟完成

### 第二步：进入ECS购买页面

**方式1：直接搜索**
```
阿里云首页 → 搜索"ECS" → 点击"云服务器ECS"
```

**方式2：从产品列表进入**
```
产品 → 弹性计算 → 云服务器ECS → 立即购买
```

### 第三步：选择购买类型

**推荐选择**：
```
┌──────────────────────────────────────┐
│  购买类型：包年包月                    │
├──────────────────────────────────────┤
│  ✅ 价格更优惠（比按量付费便宜30-50%）│
│  ✅ 适合长期使用                      │
│  ✅ 性能稳定                          │
│  ❌ 不够灵活（最少1个月）             │
└──────────────────────────────────────┘
```

如果只是测试，可以选择"按量付费"

### 第四步：选择地域和可用区

**地域选择原则**：
- 距离你的用户越近越好
- 大陆用户：选华东、华北、华南
- 海外用户：选香港、新加坡

**推荐选择**：
```
地域：华东1（杭州）或 华北2（北京）
可用区：随机选择（系统会自动推荐可用区）
```

### 第五步：选择实例规格

**经济实惠选择**：
```
1. 实例系列：经济型 e系列
2. 实例规格：2核4GB
   型号：ecs.t6-c1m2.large
   或者搜索：2核4GB
```

**性能优先选择**：
```
1. 实例系列：通用型 g7系列
2. 实例规格：2核8GB
   型号：ecs.g7.large
   或者搜索：2核8GB
```

### 第六步：选择镜像

**关键步骤！**

1. 点击"选择镜像"
2. 选择"公共镜像"
3. 操作系统选择：
   ```
   Ubuntu
   └─ Ubuntu 22.04 64位
   ```
4. ❌ 不要选择：
   - Windows（要钱且不适合）
   - 带GUI的Linux（浪费资源）

### 第七步：选择存储

**系统盘**（必选）：
```
类型：ESSD Entry（高效云盘）
容量：40GB
费用：约 ¥15-20/月
```

**数据盘**（可选）：
```
暂时不需要，后续数据量大了再加
```

### 第八步：选择带宽

**方式1：按使用量计费**（推荐新手）
```
按使用量：¥0.08/GB
适合：访问量不稳定的场景
优势：用多少付多少
预估：月均 ¥20-50
```

**方式2：固定带宽**（推荐生产环境）
```
带宽：5Mbps
费用：约 ¥30-50/月
适合：访问量稳定的场景
优势：费用可控
```

**推荐**：先选按使用量，后期流量稳定了再改固定

### 第九步：确认订单

**核对配置**：
```
实例：2核4GB 或 2核8GB
操作系统：Ubuntu 22.04
存储：40GB ESSD
带宽：按使用量
时长：1个月/3个月/1年

预估总价：约 ¥80-200/月
```

**优惠抵扣**：
- 如果有优惠券，记得勾选使用
- 新用户通常会有折扣券

### 第十步：设置ECS实例

**实例名称**：
```
political-news-server
（自定义名称，方便识别）
```

**登录凭证**（⚠️ 非常重要！）
```
选择：自定义密码
密码设置要求：
- 8-30个字符
- 包含大写字母、小写字母、数字、特殊符号
- 示例：MyServer@2024#Pass

⚠️ 务必记住这个密码！
```

**其他设置**：
```
实例释放保护：勾选（防止误删）
```

### 第十一步：确认并支付

1. 点击"确认订单"
2. 检查配置是否正确
3. 选择购买时长：
   - 1个月：测试用
   - 3个月：¥优惠券力度大
   - 1年：最优惠（7-8折）
4. 点击"支付"
5. 支付成功后会提示"创建中"
